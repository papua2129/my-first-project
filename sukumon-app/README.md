# スクモン討伐アプリ

小学校4年生の学級向け、Googleフォーム → スプレッドシート → Apps Script の討伐アプリです。児童はフォームだけに回答し、Webアプリの操作は教師が行います。画面には個人の名前や点数を表示しません。

## 構成

| ファイル | 役割 |
|---|---|
| `Config.gs` | シート構成・初期値・日付とエラー処理 |
| `DataService.gs` | 初期セットアップ、フォーム回答、設定、シート読み書き |
| `Logic.gs` | 平均・コンボ・ダメージの計算 |
| `MonsterService.gs` | Drive画像の取込と配信 |
| `BattleService.gs` | 挑戦・攻撃・取消・HP修正・終了 |
| `WebApp.gs` | Webアプリと集計データの取得 |
| `Index.html` / `Styles.html` / `Client.html` | 画面、デザイン、操作 |
| `appsscript.json` | Apps Scriptの設定 |

## 初期設定

1. このソースを新しい **Google Apps Script** プロジェクトに配置します。Apps Scriptエディタで各 `.gs` / `.html` を同名で作成して貼り付けるか、[clasp](https://github.com/google/clasp) を使用します。`appsscript.json` はプロジェクト設定で「マニフェスト ファイルをエディタで表示する」を有効にして配置します。
2. Apps Scriptのプロジェクトのタイムゾーンを `Asia/Tokyo` にします。マニフェストにも設定済みです。
3. `setupApp('DRIVE_FOLDER_ID')` をエディタから一度実行し、Googleの権限を承認します。`DRIVE_FOLDER_ID` は画像フォルダのURL末尾にあるIDへ置き換えてください。IDはコード内に固定されず、Settingsシートに保存されます。
4. 実行結果に表示されるフォームURLとスプレッドシートURLを控えます。再実行しても既存のシートとフォームを再利用します。
5. 作成されたフォームは「今日、自分はこのスクモンにどのくらい勝てましたか？」という0〜100点、5点刻みの必須選択肢を持ちます。児童にはフォームの回答URLだけを配布します。
6. 最初の回答が入ったら、教師用画面の設定で回答シート名を確認します。自動検出できない場合のみ、回答シート名・点数列・回答日時列を指定してください。列は `A` / `B` などの列記号、または見出しで指定できます。

`setupApp()` はデータ用のスプレッドシートを自動生成します。フォームの回答シート以外に `Monsters`、`Challenges`、`DailyStats`、`BattleHistory`、`Settings` を作ります。フォーム回答シートにはフォームが元データを書き込みます。`Monsters` シートの説明欄は教師が編集できます。

## Webアプリの公開

1. Apps Scriptエディタで **デプロイ → 新しいデプロイ → ウェブアプリ** を選びます。
2. 「次のユーザーとして実行」は **自分**、「アクセスできるユーザー」は **自分のみ** にします。大型提示装置では教師のアカウントで開きます。児童にWebアプリURLを配らないでください。
3. デプロイで発行された `/exec` URLを教師用端末で開きます。これが実際のアプリURLです。GitHubのソースURLとは別です。
4. フォームの回答が1件以上入った日に、図鑑からスクモンを選んで攻撃を試します。

`clasp` を使用する場合は、ローカルで `clasp login`、`clasp create --type webapp` の後にファイルを配置し、`clasp push` します。`.clasp.json` はGitに含めません。既存のApps Scriptプロジェクトに結び付ける場合は `clasp clone <scriptId>` を使ってください。

## 運用

- 図鑑からモンスターを選び、強さと初期HPを確認して挑戦開始します。
- 児童は帰りの会でフォームに回答します。攻撃時にはその日の**回答者だけ**の平均を再集計します。
- ダメージは平均点 × 倍率にコンボボーナスを加算します。最終ダメージは整数に丸めます。
- コンボは直前の攻撃が**前日**で、平均が設定値以上、かつ前日から設定値以上伸びたときに続きます。週末をまたぐ場合はコンボが途切れますが、HPは翌週へ持ち越します。
- 同じ日付のデータでは、モンスターを変えても2回目の攻撃はできません。
- 今日の攻撃の取り消し、現在HPの修正、挑戦終了は設定からできます。取り消しと修正は `BattleHistory` に記録します。
- 討伐済みのモンスターは図鑑から再挑戦できます。過去の挑戦行は残ります。
- 現在の挑戦を終了する操作は `cancelled` として記録します。履歴は削除しません。

## 設定項目

設定画面または `Settings` シートに、DriveフォルダID、回答シート名、点数列、日時列、強さ別HP、ダメージ倍率、コンボ条件、コンボボーナス、効果音ON/OFFを保存します。スプレッドシートIDとフォームURLはScript Propertiesに自動保存されます。編集するコード上の秘密情報はありません。

## 動作確認

ローカルの計算・状態遷移テストは `node tests/run-tests.js` で実行できます。回答0件・1件・24件・欠席あり・小数平均、コンボ成立/不成立/中断、HPちょうど0/超過、週またぎ、同日二重攻撃、再挑戦、画像エラー、Drive IDエラー、攻撃取消を確認します。

学校で利用する前に実際のGoogle環境で、フォーム送信→回答シート→平均表示→攻撃→再読込後のHP保持→討伐結果→図鑑反映を、教師アカウントで確認してください。Google Apps Scriptの承認とウェブアプリのデプロイは、そのアカウントの操作が必要です。
